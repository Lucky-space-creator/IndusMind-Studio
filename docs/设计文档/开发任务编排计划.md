## 1. 总体策略

- **顺序**：骨架 → Java 基础层 → Java 领域层（按 D0→D3 偏序）→ Python AI 服务 → 前端双端 → 联调测试。
- **并行窗口**：Java 领域层完成后，Python（T4）与前端（T5）可并行（契约已冻结：接口文档以 Python 服务详细设计 §3 + Java 详设 §9 为准）。
- **每批次完成标准（DoD）**：代码落盘 + 编译/构建通过 + 违规项零（自检清单见各设计文档）。
- **契约冻结**：AI 十接口（rag×5、graph×3、chat、diagnosis/run）、双端 REST 规范、表结构 43+1——开发期不再变更；确需变更须回本计划登记并同步文档。

## 2. 任务批次

### T1 环境与工程骨架（执行：项目架构智能体）
| 任务 | 产出 | 验收 |
|------|------|------|

## 3. 关键实现决策（随计划下发，开发遵循）

| # | 决策 |
|---|------|
| 1 | 看板快照触发：异常提取完成事件 + 手动刷新接口（报告 A7） |
| 2 | 工单导出：HTML 模板 + openhtmltopdf → PDF → MinIO（报告 A8）；状态 generated→导出即 exported |
| 3 | 分段在 Java（Tika 解析→分段→kb_segment→/rag/index 携片段）（报告 A3） |
| 4 | 开放 API 鉴权：Bearer Base64(ak:sk)，HMAC 列 P1（报告 A6） |
| 5 | 触发条件 DSL 由 Python 编排器解释（报告 C） |
| 6 | 模型 provider：.env 配置；演示默认 ollama（qwen2.5 + bge-m3），备选 dashscope（报告 B4） |
| 7 | 逻辑删除：deleted=0 常态，删除置 id（D2）；MyBatis-Plus 全局配置 |
| 8 | JWT：双端独立密钥与 claim（end 字段），app-user 拒绝 admin-only 角色 |

## 4. 风险与缓解

| 风险 | 缓解 |
|------|------|
| LLM 不可用/离线 | ollama 本地方案 + 模型预下载清单入部署 README；AI 降级中文提示 |
| 多 Agent 非确定性 | 验收以引用可核+越界拦截+安全否决为准（非逐字匹配） |
| 工期 | 严格 P0 范围；P1（溯源图/拖拽编排/HMAC/数据范围）明确延后 |
| 契约漂移 | 接口文档冻结；变更须登记本计划并同步三方 |
