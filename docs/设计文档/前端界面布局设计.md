# 前端界面布局设计（双端）

> 出品：项目架构智能体 / 前端开发智能体
> 版本：V2.0（**扩充用户端展示** + **成熟产品调研** + **RBAC 界面权限**）
> 关联：总纲 `docs/设计文档/系统总体架构设计.md`；后端 RBAC `docs/设计文档/Java后端详细设计.md` §7
> 定位：**用户端 + 管理端**的完整界面布局、功能展示与权限化展示策略。

---

## 1. 概述与双端定位

- 技术栈：React 18 + TypeScript + Vite；用户端 shadcn/ui + Tailwind，管理端 Ant Design 5；状态 Zustand + TanStack Query；图表 ECharts；pnpm 单仓多包。
- **用户端**（维修工程师 / 生产管理人员 / 评审体验用户）：面向**监控、问答、诊断、工单**的日常作业；**无配置/治理入口**。
- **管理端**（管理员 / 配置员）：面向**配置、治理、发布、权限**。
- 展示差异由 **RBAC 权限**驱动（见 §8）：同一套前端按权限动态渲染菜单、路由、按钮与数据范围。

## 2. 调研：成熟产品前端设计与功能布局

> 调研对象：Grafana（监控仪表盘）、Ant Design Layout/Pro（中后台布局规范）、工业 IoT 与运维平台（ThingsBoard / ThingWorx / AWS IoT SiteWise / Azure IoT Central / IBM Maximo / SAP PM 等）。
> 来源：Grafana 官方文档（Dashboards / Panel / Variables）、Ant Design 官方 Layout 文档；平台类为公开产品资料归纳。

### 2.1 Grafana（监控仪表盘）
- **仪表盘 = 多个 panel 组织为行/标签**，提供 at-a-glance 概览。
- **Panel**：query + visualization 组合；支持 **legend / tooltip / thresholds（阈值着色）/ value mappings / data links（下钻）**。
- **Variables**：顶部下拉变量（服务器/时间/机组），查看者**无需编辑面板**即可切换视图；变量同步 URL，可 `skipUrlSync`。
- **Annotations**：在时间轴上标注事件（如停机）。
- **Reporting / Sharing**：导出 PDF/PNG、快照、嵌入。
- **View 全屏模式 + 键盘快捷键**；支持 **fan-out** 把一个图按序列拆成多图对比异常。

### 2.2 Ant Design Layout / Pro（中后台布局规范）
- **尺寸**：顶部一级导航 **64px**、二级 **48px**；展示类页面一级 **80px**、二级 **56px**；侧边宽度 `200+8n`。
- **布局范式**：上中下、顶部-侧边、侧边（左导航+顶部辅助菜单）；**固定头/固定侧栏**；**响应式**按 `xs/sm/md/lg/xl/xxl/xxxl` 断点收折侧栏。
- **交互**：一级与末级导航在视觉上被强调；当前项优先级最高；**收起时当前样式上移到父级**；左侧支持手风琴/全展开。
- **视觉**：深底用大色块强调父级、浅底用"高亮火柴棍"、父级用字体高亮。
- **Design Token**：`headerHeight=64`、`siderWidth`、`fontSize=14` 等统一主题。

### 2.3 工业 IoT / 运维平台（功能布局）
- **设备管理**：设备台账/地图分布、设备详情（指标趋势、状态、告警历史）。
- **实时监控**：仪表盘网格 + 时序图 + 阈值告警着色 + 时间范围选择器。
- **告警中心**：告警列表 + 等级 + 状态流转（未处理/处理中/已闭环）+ 确认/指派。
- **工单/维护**（Maximo/SAP PM）：工单列表 + 详情（设备、根因、备件、步骤、停机损失）+ 状态流转。
- **告警与工单联动**：从告警一键生成工单。

### 2.4 通用中后台框架（Ant Design Pro / Vben / Arco Pro）
- **RBAC 落地惯例**：登录返回 `menus/permissions` → **动态菜单 + 动态路由 + 按钮级权限指令（`v-auth`/`<Auth>`）**；无权限不渲染而非仅禁用；后端强制校验。

### 2.5 调研结论 → 设计启示
1. **仪表盘用 Panel 网格 + 行分组**，顶部放**全局变量**（设备、时间范围、机组）与**时间范围选择器**。
2. **告警中心独立成区**，状态可流转并与工单联动。
3. **设备详情** = 概览卡 + 指标趋势 + 告警时间线。
4. **图表**统一支持阈值着色、Tooltip、图例、下钻（data link）。
5. **RBAC 四层**：菜单 / 路由 / 按钮 / 数据；按钮级用权限包裹组件。
6. **引用溯源**用**抽屉侧滑**（不打断上下文）。
7. **空状态 / 骨架屏 / 进度反馈**为标配；监控类提供**全屏与时间缩放/平移**。
8. 布局采用 **顶部导航 + 时间范围 + 侧边/内容**，符合监控类与中后台范式。

## 5. 设计系统与基调

- **框架尺寸**（对齐 Ant Design）：用户端一级导航 64px、二级 48px；管理端侧边宽度 200px（`200+8n`，收起 80px）。
- **配色**：语义色 token；工业风主色（深蓝/青）；状态色 正常=绿、预警=橙、故障=红；图表阈值着色。
- **排版**：基准 16px、行高 1.5；指标数字用大号/等宽强调。
- **间距**：8px 栅格；触控目标 ≥44×44px。
- **组件**：用户端 shadcn + 反 AI 味；管理端 Ant Design 表格/表单。
- **禁忌**：紫→蓝渐变、卡片套卡片、emoji 当图标、Inter 一把梭。

## 8. RBAC 权限与界面展示（重点）

### 8.1 权限模型（五层）
```
端(user/admin) → 模块(菜单) → 页面(路由) → 操作(按钮) → 数据范围
```
- 权限数据源：后端 `sys_permission` / `sys_role_permission` / `sys_role_data_scope`（见 Java 后端详细设计 §7）。
- 登录成功后返回当前用户：`roles`、`menus`、`permissions`、`dataScope`。

### 8.2 权限编码规范
```
<模块>:<资源>:<动作>        例：device:info:read、device:info:write
                            workorder:work_order:export
                            publish:service:publish
```
- 动作：`read` / `write` / `publish` / `delete` / `export`。
- 前端常量集中在 `shared-types/permission.ts`，禁止硬编码字符串散落。

### 8.3 前端权限落地（四层）
| 层级 | 落地方式 | 无权限表现 |
|------|----------|------------|
| 菜单 | 由 `menus` 生成导航，逐项过滤 | 菜单项不渲染 |
| 路由 | 动态路由注册 + 路由守卫校验 `permission` | 跳转 403 页 |
| 按钮/操作 | `<Auth code="...">` 包裹 或 `usePermission().has(code)` | **不渲染**（非仅置灰），或按需置灰 |
| 数据范围 | 请求携带 scope，后端过滤；前端提示范围（如"仅本产线"） | 仅展示授权范围内数据 |

- 组件级：敏感字段/卡片按权限渲染（如成本、库存仅授权角色可见）。
- **用户端与管理端**：用户端永不加载管理端菜单与路由；两套 `menus` 隔离。

### 8.4 角色 × 界面权限矩阵
| 界面/操作 | 管理员 | 配置员 | 维修工程师 | 生产管理人员 | 评审用户 |
|-----------|:------:|:------:|:----------:|:------------:|:--------:|
| 用户端·看板/告警 | – | – | ✅ | ✅ | ✅(只读) |
| 用户端·智能问答 | – | – | ✅ | – | ✅(只读) |
| 用户端·协同诊断 | ✅(测试) | – | ✅ | 只读结论 | ✅(只读) |
| 用户端·维修工单（下载） | – | – | ✅ | 只读 | ✅(只读) |
| 用户端·知识检索 | – | – | ✅ | – | ✅(只读) |
| 管理端·设备配置 | ✅ | 只读 | – | – | 只读 |
| 管理端·知识库/文档关联 | ✅ | ✅ | – | – | 只读 |
| 管理端·数据管理 | ✅ | – | – | – | 只读 |
| 管理端·Agent与流程 | ✅ | ✅ | – | – | 只读 |
| 管理端·发布监控（发布） | ✅ | ✅ | – | – | 只读 |
| 管理端·账号权限 | ✅ | – | – | – | – |
| 管理端·审计日志 | ✅ | – | – | – | – |

> 矩阵与后端 `sys_role_permission` 一致；数据管理权限以需求 §1.4 为权威（配置员无 data 权限，见需求分析报告 A1）；知识检索为用户端只读辅助入口（权限点 knowledge:search:read，A4）。

### 8.5 双重校验
- 前端**隐藏**无权限入口（体验）；后端**强制**校验（安全，返回 403）。
- 前端权限仅用于展示控制，**不得**作为安全边界。

## 9. 组件与复用

- `shared-ui`：Panel 容器、状态标签、阈值着色图表、时间范围选择器、设备/变量选择器、引用卡片、进度条、骨架屏、空状态。
- `shared-auth`：`<Auth>`、`usePermission`、`PermissionProvider`。
- 复用前端 skill：react-bits（动效/背景/文字动画）、shadcn/ui（用户端基础组件）。
- 规范：单文件自包含、props 驱动；动画清理 `requestAnimationFrame`，`prefers-reduced-motion` 降级。

## 10. 交互与状态

- **进度反馈**：文档处理、索引构建、诊断执行均显示进度/阶段结果。
- **错误提示**：统一中文原因 + 处理建议，避免无响应或崩溃。
- **引用溯源**：问答/诊断/工单中的引用点击弹出**原文抽屉**。
- **下钻（data link）**：图表点选可跳转到设备详情/告警详情。
- **全屏与时间缩放**：监控图表支持全屏、缩放、平移（对齐 Grafana 交互）。
- 数据获取：TanStack Query 缓存与失效；全局状态用 Zustand。

## 11. 响应式与可访问性

- 断点对齐 Ant Design：`xs 480 / sm 576 / md 768 / lg 992 / xl 1200 / xxl 1600`；侧栏按断点收折，收起时当前项样式上移父级。
- 对比度 ≥4.5:1；键盘可达；可见焦点环；图表配图例/Tooltip，不只靠颜色。

## 12. 与后端对接

- 用户端调 `/api/user/**`，管理端调 `/api/admin/**`；`shared-api` 统一 Token 注入与错误处理。
- 登录接口返回 `menus` / `permissions` / `dataScope`。
- 契约由项目架构智能体统一维护，前端按 OpenAPI 生成类型到 `shared-types`。
